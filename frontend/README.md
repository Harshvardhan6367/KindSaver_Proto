# KindReport Frontend

Separate React + Vite frontend for the Jaipur demo.

## Run

```bash
npm install
npm run dev
```

Default backend:

```bash
http://127.0.0.1:4000
```

Override with:

```bash
VITE_API_BASE_URL=http://127.0.0.1:4000 npm run dev
```

## Screens

- Public Jaipur map with filters.
- Citizen report form.
- Ticket tracking timeline.
- Admin dashboard and incident queue.
